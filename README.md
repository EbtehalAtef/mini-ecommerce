# Mini E-commerce Website

A simple front-end e-commerce website built with HTML, CSS, and JavaScript. The project allows users to browse products, search and filter items, sort products, view product details, and manage a shopping cart.

## Features

- **Dynamic Products:** Fetches products and categories from the Fake Store API.
- **Search:** Search for products by name.
- **Category Filter:** Filter products by category.
- **Price Filter:** Filter products using minimum and maximum prices.
- **Sorting:** Sort products by name, price, and rating in ascending or descending order.
- **Pagination:** Display products across multiple pages.
- **Product Details:** View detailed information about each product.
- **Shopping Cart:** Add products to the cart and remove them.
- **Local Storage:** Save cart items and filter settings so they remain available after refreshing the page.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API
- Local Storage
- Fake Store API

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Make sure you have an internet connection to load products from the API.

## API

This project uses [Fake Store API](https://fakestoreapi.com/) to fetch product and category data.
